# Travel Expense Analysis & Financial Insights Dashboard

## 📌 Project Overview

This project analyzes travel and expense data to identify spending patterns, financial trends, employee-wise expenses, site-wise costs, and expense efficiency.

The project combines Python, Pandas, SQL, and Power BI to perform end-to-end data analysis and visualization.

> **Note:** The dataset used in this project is a synthetic practice dataset created for learning and portfolio purposes.
